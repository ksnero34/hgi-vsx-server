# HGI Developer Extension Pack

한화손해보험 내부 개발자를 위한 필수 VSCode Extension 모음입니다.

## 포함된 Extension

### Python 개발
- **Python** - Python 언어 지원
- **Pylance** - Python 언어 서버 (IntelliSense, 타입 체킹)

### JavaScript/TypeScript 개발
- **ESLint** - JavaScript/TypeScript 코드 품질 검사
- **Prettier** - 코드 포맷터

### Java/Spring 개발
- **Language Support for Java** - Java 언어 지원
- **Debugger for Java** - Java 디버거
- **Test Runner for Java** - JUnit 테스트 실행
- **Maven for Java** - Maven 프로젝트 지원
- **Spring Initializr** - Spring Boot 프로젝트 생성
- **Spring Boot Tools** - Spring Boot 개발 도구
- **HGI JPA Editor** - 한화손보 JPA Native Query 에디터

### 기타 언어
- **Go** - Go 언어 지원
- **Rust Analyzer** - Rust 언어 지원

### 유틸리티
- **Code Runner** - 코드 즉시 실행
- **Material Icon Theme** - 파일 아이콘 테마
- **Remote - WSL** - WSL 환경에서 개발

## 설치 방법

1. VSCode Extension 탭에서 "HGI Developer Extension Pack" 검색
2. Install 클릭
3. 모든 extension이 자동으로 설치됩니다

## 업데이트

Extension Pack을 업데이트하면 포함된 모든 extension도 최신 버전으로 업데이트됩니다.
